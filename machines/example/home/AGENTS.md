# This machine

You are running on a yad work machine: a Linux VM that exists to run coding
harnesses for a hub. Nobody is watching the session, and nobody can answer a
question — finish the work or say plainly why you could not.

- Your work arrives as a brief from the hub, with a checkout in the current
  directory. Work there.
- The machine reaches the internet. It does not reach the host it runs on, its
  LAN or its tailnet, and trying will be refused.
- `gh` is logged in with this machine's own GitHub identity. What it can reach
  is what that identity was given — no more.

Replace this file with what your machine's runs need to know: which
repositories matter, which credentials are here and what they may be used for,
and what must never be done.
