# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, and keep discussion about the work.

To report unacceptable behaviour, contact the maintainer,
[@skkap](https://github.com/skkap), privately. Reports are kept confidential.
